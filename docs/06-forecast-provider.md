# Looopでんき予報取得設計

## 6.1 データソース

取得対象：

https://looop-denki.com/home/denkiforecast/

取得情報：

- 対象エリア：北海道
- 対象日時
- 30分ごとの電源料金単価
- 取得日時
- データソース

1日48コマの取得を基本とする。

## 6.2 取得方式

一般開発者向けの公式APIは、利用可能であることを確認できていないため、初期開発段階で以下を調査する。

1. 公式ページの通信方式
2. 料金データの取得経路
3. 自動取得に関する利用条件
4. 継続利用時の安定性
5. 仕様変更への対応方法

料金取得部分はForecast Providerとして独立させる。

安定した取得方式を確保できない場合は、代替データソースを検討する。

## 6.3 取得タイミング

| タイミング | 処理 |
|---|---|
| システム起動時 | 当日予報取得 |
| 毎日16:15 | 翌日予報取得 |
| 取得失敗時 | 一定間隔で再取得 |
| Web UIからの操作 | 手動再取得 |

運用時間外にシステムが停止していた場合でも、次回起動時に当日予報を取得して動作する。

## 6.4 データ検証

- 対象エリアが一致していること
- 対象日が正しいこと
- 48コマが取得できていること
- 時刻が連続していること
- 単価が数値として取得できていること
- 重複・欠損がないこと
- データが有効期限内であること

過去日の料金データを当日の予報として流用しない。
