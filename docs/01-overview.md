# プロジェクト概要

## 背景

Looopでんきの市場連動型プランでは、30分単位で電源料金単価が変動する。

この価格変動を利用し、電力単価が安い時間帯に蓄電池を充電し、高い時間帯には商用電源からの供給を停止することで、電力購入費用の削減が期待できる。

現状はスマートプラグのタイマー設定を手動で変更しているが、電力単価は日々変動するため、設定作業が運用負担となっている。

本システムでは、Looopでんきの料金予報を自動取得し、電力単価に基づくスマートプラグのON/OFF制御を自動化する。

また、初期リリースからWeb UIを実装し、料金予報・制御状態・実行履歴を可視化する。

## 目的

1. Looopでんきの料金予報を自動取得する。
2. 電力単価に応じた充電制御スケジュールを自動生成する。
3. SwitchBotスマートプラグを自動制御する。
4. 日々の手動タイマー設定作業を不要にする。
5. Web UIから現在の料金・制御状態・運転予定を確認できるようにする。
6. Web UIから手動操作や制御条件の変更を可能にする。
7. 制御履歴と推定節約額を記録・可視化する。

## 基本方針

- Dockerによるコンテナ運用を基本とする。
- 特定のホストOSやハードウェアへの依存を避ける。
- バックエンドはPythonで実装する。
- Web UIは初期リリースの必須機能とする。
- 業務時間中の稼働を主目的とし、24時間稼働は必須としない。
- 外部サービスとの連携部分は独立したモジュールとする。
- 自動制御と手動制御の競合を防止する。
- 料金データが不正または取得できない場合は、安全側の制御を優先する。
