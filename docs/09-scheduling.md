# スケジューリング設計

## 9.1 運用例

| 時刻 | 処理 |
|---|---|
| 08:50 | システム起動 |
| 08:51 | 初期化・状態確認 |
| 08:52 | 当日予報取得 |
| 08:53 | 制御計画生成 |
| 09:00 | 自動制御開始 |
| 運用時間中 | 料金予報に基づく制御 |
| 16:15 | 翌日予報取得 |
| 18:00 | スマートプラグON |
| 18:05 | 履歴保存・終了処理 |

時刻はWeb UIの設定画面から変更可能とする。

## 9.2 起動時

- 設定読み込み
- DB接続確認
- SwitchBot API接続確認
- プラグ状態確認
- 安全側への初期化
- 当日予報取得
- スケジュール生成
- 自動制御開始

運用開始時刻を過ぎてから起動した場合も、残り時間を対象として計画を再生成する。

## 9.3 終了時

原則として、スマートプラグをONへ復帰させてから終了する。

ただし強制終了・通信障害・ホスト停止では終了処理を保証できないため、制御プログラムに依存しない安全復帰策も検討する。
